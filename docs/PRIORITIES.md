# Project Priorities
Listed from most to least important.

## 1. Experiment with CI/CD, infrastructure-as-code, cloud deployment, and other DevOps work.

I've solved a fair number of problems in this space within my professional life, but I've hardly ever explored the space broadly within personal projects. This repo serves to hone my skills in those environments, experiment with related concepts, and to serve as a template for more serious projects within that space. See the end of ARCHITECTURE.md for more info on directions that part of the project may take.

## 2. Experiment with Claude Code and other agentic development workflows.

Development using agentic AI is clearly a very useful skillset, but until now I've avoided it for a few reasons:

1. I don't want to risk letting my development skills atrophy. I'm convinced being able to code without AI will always have *some* value, and depending on it too heavily risks letting those skills atrophy.
2. It's an unnecessary expense. I've seen people run up bills of hundreds of dollars on minor personal projects. That seems wasteful when I can just do it myself, or get AI assistance from a web interface if I really want it.
3. Reviewing code changes for quality is more draining and less rewarding than traditional coding, even if it's faster.

Those points still stand, but I think all three can be mitigated if approached carefully. DevOps work, especially AWS cloud resource setup and configuration, involves a tremendous amount of busywork and boilerplate code. AI is especially useful for automating that type of work away, making this project a uniquely good place to start experimenting with agentic AI.

## 3. Experiment with LLM-driven art.

The actual shape of the web application contained in this project is incidental, so why not let Claude be creative with it? I'm a member of "Are We Art Yet?", an online art community focused on bridging gaps between traditional artists and AI users, and demonstrating how AI can be used to help artists instead of displace them. They've ran a number of fascinating creative projects that focused on granting Claude artistic agency, and I'm not going to turn down a perfectly good excuse to do more of that.
